# TechWorld 🩷🖤

Site educativo sobre tecnologia desenvolvido por Bruna Martins como projeto de portfólio.

## Funcionalidades
- 12 artigos introdutórios sobre IA, Front-End, Back-End, bancos de dados e segurança
- Busca em tempo real e filtros por categoria
- Leitura de artigos em janela modal
- Quiz interativo com cinco perguntas e pontuação
- Design responsivo em rosa e preto

## Tecnologias
HTML5, CSS3 e JavaScript puro.

## Como executar
Abra `index.html` no navegador ou publique pela branch `main` usando GitHub Pages.
